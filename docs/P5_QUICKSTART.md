# 轻邮：日常试用卡片

适用于本机浏览器版本。先用演示熟悉操作，再由你主动决定真实操作。

1. **启动**：在项目文件夹双击 `体验演示.command` 练习，页面应显示“演示模式”。使用自己的邮箱时双击 `启动轻邮.command`，页面应显示尚未连接；启动不会自动连接、扫描或退订。需要单独窗口时见 [MACOS_APP.md](MACOS_APP.md)。
2. **连接**：真实模式点击“连接 Gmail”，由你完成 Google 只读授权。缺少客户端文件时按页面说明准备；“文件存在”不代表连接成功。连接成功后才能看到同账号已保存的清单。
3. **扫描与保护**：只有主动点击扫描才读取新邮件；先用默认的最近 30 天、促销邮件、最多 100 封。想保留的订阅先加保护，保护变化会让旧计划失效。
4. **预览与确认**：选择具体订阅，预览对象和理由。真实预览会读取所选代表邮件并验签，之后还需单独确认才能发送请求。不要为了试用撤销已有保护，也不要对“结果待确认”的对象重试。
5. **看结果**：打开“操作记录”。“请求已接受”仅表示收到接受回执；“结果待确认”表示可能已发出但无法确认；“需要人工处理”表示没有可靠自动方式，需本人查看原邮件。这三种都不保证永久停信。
6. **退出**：关闭弹窗只隐藏任务，关闭网页也不停止服务。使用任务里的停止按钮，等待在途操作结束，然后回启动终端按 **Control+C** 并等命令结束。再次启动时使用新显示的网址。提示已有实例时回原窗口，不删除锁文件、不强关未知进程。

终端备用入口（先进入项目目录）：

```sh
/bin/zsh scripts/launch-v2.sh demo
# Use live instead of demo only when you intend to open real-mailbox mode.
```

启动器使用已有 `.venv-v2-p5`，其次 `.venv-v2`；不会改用系统 Python。`environment_missing` 表示没有项目环境，`environment_incomplete` 表示依赖不完整，`startup_failed` 表示目录或端口等启动故障。环境重建方法见 [V2_REBUILD.md](V2_REBUILD.md)，已有可用环境无需重装。

**数据与备份**：默认真实目录是项目 `.local/v2-live/`，演示目录是 `.local/v2-demo/`；自定义启动目录时以指定路径为准。完全退出后，把整个对应目录复制到自己保管的本机加密位置；其中可能有令牌和邮件资料，不能公开或发给他人。恢复时保留原目录，把备份复制到新目录，用同一版本的 `--data-dir` 指向它。备份后的真实请求不能被撤回，旧备份可能缺少去重记录，不能据此再次提交。详细步骤见 [V2_USAGE.md](V2_USAGE.md)。备份恢复只用合成目录验证过；真实令牌恢复、跨电脑恢复和旧版本降级未测。
